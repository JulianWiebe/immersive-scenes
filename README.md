# Immersive Scenes

A FoundryVTT **v14** module for cinematic, visual-novel style scenes that are drawn **inside the Foundry canvas**. The battlemap you are on stays the stage: an immersive scene takes over the canvas temporarily. Everyone can still pan and zoom, and pings, cursors and rulers keep working. No Foundry scene is created or switched.

> Work in progress. See the CHANGELOG for what is implemented.

## Development
No build step: plain ES modules.

```bash
npm install
npm run check   # lint + validate + test
```
